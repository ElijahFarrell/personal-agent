# Copywriting Skill
## When to Use This Skill
- Writing LinkedIn posts
- Drafting newsletters
- Writing outreach messages
- Creating sales copy or offer descriptions
- Writing hooks or introductions for any content
- Any content that needs to persuade, engage, or convert
## Core Writing Philosophy
The goal of all writing is to communicate one clear idea, prove it, and move the reader to think or act differently. Never write to impress. Write to connect and convert.
Always load `frameworks.md` before writing any piece of content.
Always load `hooks.md` before writing any opener or headline.
For brand-aligned content, also load the `brand-voice` skill.
## The Writing Process
1. Identify the ONE idea this piece communicates
2. Choose the right framework from frameworks.md
3. Write the hook first using hooks.md
4. Build the body using the chosen framework
5. End with a clear call to action or insight
6. Cut anything that doesn't serve the core idea
## Quality Checklist
- [ ] Does the hook immediately tell the reader what they'll get?
- [ ] Is there one clear idea — not three?
- [ ] Does the logic flow: conclusion → arguments → evidence?
- [ ] Is every sentence earning its place?
- [ ] Does it end with a clear next step or insight?
