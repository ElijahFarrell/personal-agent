# AI Audit Skill
## When to Use This Skill
- A prospect has agreed to receive an audit
- Scoping a new client engagement
- Identifying where AI/automation can create the most value in a business
- Prioritizing which AI opportunities to build first
- Preparing an executive presentation of findings
## Core Philosophy
An AI audit is not a sales pitch. It is a genuine analysis of where AI can create real value for a specific business. The audit earns trust by demonstrating expertise before asking for money.
The audit should answer three questions:
1. Where is this business losing the most time to manual, repetitive work?
2. Which of those areas would benefit most from AI automation?
3. What would the ROI look like if we solved those problems?
## The Two-Week Audit Process
Load `process.md` for the full methodology.
Load `opportunity-matrix.md` for the prioritization framework.
**Week 1 — Discovery:**
- Stakeholder interviews (understand the business, the pain points, the goals)
- Process analysis (map the current workflows — Acquisition, Delivery, Support, Admin)
- Ops Canvas mapping (visual map of the full business operation)
**Week 2 — Solution Design:**
- Identify AI opportunities across all mapped processes
- Prioritize using the Opportunity Matrix (Impact vs. Effort)
- Build ROI estimates for top opportunities
- Create opportunity briefs for each recommended solution
- Prepare executive presentation
## Deliverables
1. Ops Canvas — visual map of current business processes
2. Opportunity Matrix — prioritized list of AI opportunities
3. Opportunity Briefs — one-pager per recommended solution
4. ROI Estimates — time/cost savings per opportunity
5. Executive Presentation — full findings and recommendations
