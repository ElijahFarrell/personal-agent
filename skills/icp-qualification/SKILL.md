# ICP Qualification Skill
## When to Use This Skill
- Evaluating whether a specific prospect fits the ideal client profile
- Building a target outreach list
- Deciding whether to pursue a lead or discard them
- Defining the ICP for a new niche or offer
## Core Philosophy
This is not a thinking exercise — it is a filter. You are looking for evidence. If you cannot clearly check a box, treat it as a no.
Your objective: identify clients who have a genuine transformation, an aligned audience, and clear signals of trust and demand. If a prospect fails multiple core checks, discard and move on. Time is the scarcest resource.
## The ICP Definition Process
Before qualifying anyone, define the ICP clearly. Load `questions.md` and answer every question in writing. Do not keep answers in your head — writing forces clarity and exposes gaps.
Only after the ICP is defined should you run prospects through the `checklist.md` filter.
## Qualification Rule
- **2 or more boxes unchecked → Discard**
- **Most boxes checked → Pursue**
## Bundled Files
- `checklist.md` — The qualification filter. Run every prospect through this.
- `questions.md` — ICP definition questions. Complete before any outreach campaign.
